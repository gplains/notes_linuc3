# 209 参考:UFW

## ufw

Ubuntu で利用可能なiptablesのラッパー

### Ubuntuの場合

- インストール～活用
  
  ```
  # 標準では無効
  sudo ufw status ; iptables -L
  # 有効化する
  sudo ufw enable ; iptables -L
  # 22/tcp を許可
  sudo ufw allow 22/tcp ; iptables -L
  # 53/udp 53/tcp を許可
  sudo ufw allow 53 ; iptables -L
  ```
